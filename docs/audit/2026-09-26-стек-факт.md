# Стек «Инспектора ИИ» — факт на 26.09.2026

> **Обновление 26.09 (T-107, ADR-0003):** строка `node:sqlite` 🔴 закрыта — хранилище переведено на PostgreSQL 18 во всех
> профилях (сервер `postgres:18-alpine` 18.6 в compose, PGlite 0.5.8 = PostgreSQL 18.3 в dev и тестах). Снимок ниже — на момент аудита.

Сверка по трём слоям: что **объявлено** в манифесте, что **реально стоит** (lock, пин образа, установлено на маке)
и **как библиотека вызывается в коде**. Причина — случай PaddleOCR: в lock стояла 2.x, но код никто не запускал,
и он написан под API, которого в актуальной 3.x уже нет.

Оценка: ✅ актуально · 🟡 минор позади · 🟠 мажор позади или код под старый API · 🔴 уязвимость, EOL, мёртвый код или расхождение.

## Сначала главное — что в коде устарело или не работает

| # | Что | Факт | Оценка |
|---|---|---|---|
| 1 | PaddleOCR в ансамбле OCR | `ocr_ensemble._paddle_reader` вызывает API 2.x: `PaddleOCR(lang="ru", show_log=False)`, `.ocr(img, cls=True)`. В 3.x `show_log` убран, `.ocr()` заменён на `.predict()`, формат ответа другой. Пакета нет ни в образе, ни на маке: код ни разу не исполнялся. Движок называется `paddleocr-vl`, но вызывает классический PaddleOCR, а не PaddleOCR-VL. Пин `paddleocr<3` (T-083) держит мёртвый код на старом API | 🔴 |
| 2 | GLM-OCR и MinerU в ансамбле | Адаптеры без `reader`: при вызове `NotImplementedError`. Ансамбль ловит любой сбой стороннего движка и молча исключает его. Комментарий «включаются сами, как только модуль есть» неверен: даже после установки пакета они ничего не распознают и не скажут об этом | 🔴 |
| 3 | Tesseract dev ≠ стенд | Мак — 5.5.3 (brew). Образ ML — из apt базы `python:3.12-slim` (Debian trixie) → 5.5.0, версия не закреплена. OCR разработки и стенда — разные сборки движка; пороги качества калибруются на маке | 🟠 |
| 4 | Node на маке | Разработка — 25.9.0 (EOL 2026-06-01), образ и гейт — 24. `.nvmrc` = 24 с T-087, сам Node не переключён | 🔴 |
| 5 | Роутер веба | Код импортирует из `react-router-dom` (прокладка v7); актуальная линия — `react-router` 8.x, где этого пакета уже нет | 🟠 |
| 6 | Семантика ONNX | Модель одна и та же, но на маке файл arm64, в образе — x86 (avx2); порог `SEM_MIN` калиброван на arm64 (записано в Dockerfile) | 🟡 |
| 7 | Советник: MLX | `MlxProvider` зовёт `mlx_lm.generate(model, tok, prompt=…, max_tokens=…)`; `mlx_lm` не установлен нигде (последняя 0.31.3) — путь не исполнялся, совместимость с текущим API не проверена | 🟠 |
| 8 | Базовый образ Python | Пин `python:3.12-slim@sha256:2f17…` старше текущего тега (`…f77a…`): внутри не последний патч 3.12 и не последние пакеты Debian. Недельная пересборка гейта digest не обновит — пин меняется только руками | 🟡 |

Остальной код вызывает библиотеки по актуальным API: pydantic 2 (без `.dict()`, `class Config`, `@validator`),
FastAPI без `on_event`, pypdfium2 5 (`render().to_pil()/.to_numpy()`, `get_textpage`), Pillow без удалённых
`ANTIALIAS/textsize`, numpy без удалённых алиасов, `structural_similarity` без `multichannel`, Ollama `/api/embed`
и `/api/chat`, zod 4 без устаревших `errorMap`/`z.string().email()`, pdf.js с `isEvalSupported: false`.
