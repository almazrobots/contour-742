# Области ТЗ для «Детальной трассы» (T-097)

Один файл — один раздел ТЗ (`id` совпадает с разделом `docs/tz/tz-decomposition.yaml`).
Проверка раздела: `node scripts/tz-detail.mjs S4`, строки раздела для разметки: `node scripts/tz-detail.mjs --dump S4`.

```yaml
Области ТЗ на странице PDF для «Детальной трассы» (T-097). Размечен весь ТЗ: 20 файлов, S0 (обложка) … S14.
Область — фрагмент текста ТЗ с точностью до слова, найденный по фразам в текстовом слое PDF
(data/seed/tz-layout.json, scripts/tz-layout.mjs). Области на странице ищутся по порядку: следующая
начинается после предыдущей.

  page      — страница PDF (не печатный номер)
  from, to  — фраза начала и фраза конца, обе включительно; без to область заканчивается на конце from
  band      — строка таблицы: берётся полоса страницы по высоте от строки с from до строки с to, все колонки
  atoms     — атомы ТЗ (docs/tz/tz-decomposition.yaml), в которые разложен фрагмент
  model     — прямая ссылка на узел модели (BP/BF/BO), когда фрагмент называет бизнес, а не требование
  head      — заголовок пункта ТЗ: своих требований нет, статус берётся по атомам пункта
  none      — требований нет, с причиной
  candidate — фрагмент содержит требование, которое не разложено ни в один атом: кандидат в декомпозицию
  whole     — вся страница без текстового слоя (обложка-изображение); text — текст, перенесённый вручную
  gap       — пробел модели (GAP-* в model.yaml), к которому относится фрагмент: кандидат или расхождение
  matrix    — разделы Матрицы, которые покрывают строку таблицы; число параметров считается по data/seed/matrix.json

scope — где на страницах лежит раздел. Строка внутри scope без области — ошибка гейта («не размечено»).
```
