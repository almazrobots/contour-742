# ADR-0002. Правовой режим корпуса

## Контекст

`yandex:2026.09 ЛЦТ НАДЗОРИУМ/corpus-ABC` — реальные ИД и РД, переданы неформально,
публичное использование запрещено, есть персональные данные. Локальный диск почти полон.

## Решение

1. Корпус не скачивается целиком. Отдельный файл читается потоком (`rclone cat`) для
   разовой отладки парсера; ничего из него не сохраняется в репозиторий — ни файлы,
   ни извлечённый текст, ни фикстуры.
2. Демо, тесты и скриншоты работают только на синтетическом наборе, который генерирует
   `ml/synth/generate.py`: свои объекты, свои штампы, свои шифры.
3. Из корпуса допустима лишь обезличенная статистика (dpi, доля сканов, форматы листов).

## Последствия

Качество OCR на реальных сканах на маке оценивается только вручную и не публикуется.
