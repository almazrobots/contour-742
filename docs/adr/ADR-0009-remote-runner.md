# ADR-0009. Удалённый раннер

## Контекст

С T-104 гейт и мутации шли на маке (MacBook Air M4, 24 ГБ) через общий замок `scripts/heavy.sh`. На волне W1 параллельно
работают три-четыре ветки. Свободный диск мака упёрся в порог правила №0 (20 ГБ), Stryker в 2 потока грел машину,
а замок без очереди блокировал срочную сборку стенда. Владелец 28.09 решил: код правится на маке, всё, что запускается, —
на удалённом сервере.

## Решение

- Раннер — 158.255.3.179 (HOSTKEY, 32 ядра, 62 ГБ, 846 ГБ), каталог `/opt/w1-gate`. Сервер общий с разбором T-165:
  раннеру ядра из `/opt/w1-gate/cpus` (сейчас 24–31), `nice`, `ionice -c3`, GPU не используется (`CUDA_VISIBLE_DEVICES=`),
  образы с префиксом w1-, диск до 150 ГБ. Корпус и ключи корпуса на раннер не попадают (ADR-0002), только код из git.
- `scripts/remote-run.sh [--get путь]… <команда>` на маке: push HEAD по SSH в bare-репо раннера (серверу не нужны
  ключи GitHub), серверная половина `scripts/runner/run.sh` из того же коммита — замок flock, свой worktree на ветку,
  синхронизация pnpm и uv, запуск; лог — `/opt/w1-gate/logs`, отчёты — `--get` обратно на мак.
- Инструменты раннера ставит `scripts/runner/bootstrap.sh` в `/opt/w1-gate/tools` (node 24, pnpm из packageManager,
  uv 0.10.7, gitleaks 8.30.1) — система и чужие каталоги не трогаются.

- Уточнение владельца 28.09: на раннере и **отладка** — тесты по одному файлу, dev-стенд ветки (T-183), а мак — только
  редактор. `remote-run.sh --wip` переносит рабочее дерево с незакоммиченным (tar по SSH, манифест удалённых файлов)
  в worktree `<ветка>.wip`; `--light` — лёгкая команда без очереди замка на двух ядрах с nice 19. На маке для W1
  `pnpm install`, `uv sync` и `docker build` не выполняются.

## Последствия

- Мутации — 8 потоков, пока T-165 держит ядра 0–23, дальше — по договорённости; время гейта `--quick` — 4–5 мин.
- Раннер — Linux x86: всплыли различия с macOS (GNU dd в `at-rest-encrypt.sh` резал части мельче — дефект прода на
  GPU-профиле; BSD `stat` в фикстуре). Это плюс: прод тоже Linux.
- Сервер почасовой; если его удалят после T-165, раннер переезжает на другой хост тем же `bootstrap.sh`.
