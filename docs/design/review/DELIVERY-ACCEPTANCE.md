## Незакрытые проверки

- Приём пакета с реестром: корректные стадии/редакции, отказ файла и исправление.
- Административное изменение справочников, мониторинг и отказные ветки прав.
- Остальные варианты разметки, структурированные источники и восстановление после потери ответа.
- Независимое прохождение инструкций читателем без подсказок автора.
- Аудиты покрытия ТЗ, критиков и пробелов выполняются в трёх отдельных сессиях по поручению пользователя. Их готовность здесь не заявляется.

## Обнаруженные ограничения

- После последнего решения очередь блокируется; Z уже не возвращает решение.
- Имя RD.pdf не устанавливает стадию РД без корректного реестра.
- Ошибка 503 до записи проверена отдельно. Потеря ответа после возможной записи требует чтения текущего исхода, а не слепого повтора.
- Основной интерфейс и приложение разметки имеют отдельные сеансы входа.

Цель не считается закрытой только на основании числа страниц, HTTP 200 или успешного воспроизведения.
