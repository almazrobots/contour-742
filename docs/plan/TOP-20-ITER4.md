## Порядок

1. Сразу, без внешних зависимостей: T-059 (интерфейс), T-061 (реальный корпус), T-065 (бенчмарк).
2. Чтобы было что открыть и показать: T-060 (стенд) → T-075 (нагрузка).
3. Запросить у организатора как можно раньше, ответ идёт долго: T-067 (контракт «РиН»), T-078 (вопросы).

## ИАИС «РиН»: что известно

- Основание — постановление Правительства Москвы № 397-ПП (ред. 775-ПП); оператор — ДИТ Москвы, координатор —
  Мосгосстройнадзор. ТЗ §9.6: REST + JSON, pull-модель, POST /api/v1/inspection/{process_id} только для
  финализированного протокола, клиентские сертификаты УКЭП, повторы 1/5/15 мин, PENDING_SYNC, статусы предписаний.
- Публичной спецификации API «РиН» нет — только положения и распоряжения о вводе в эксплуатацию.
- В прототипе: заглушка «РиН» с повторами и статусами синхронизации; настоящий контракт — T-067.

## Находки параллельного исследования (репозиторий `building-tech-CJM`, research/legal-frame.md)

Агенты CJM-исследования читали первоисточники на mos.ru, Гаранте и КонсультантПлюсе. Для «Инспектора ИИ» важно:

1. **Правовая опора ИИ в Москве.** ПП Москвы от 12.05.2026 № 1318-ПП ввело в Положение о региональном
   госстройнадзоре (ПП Москвы от 15.12.2021 № 2078-ПП) раздел 9(1): на период эксперимента по ст. 14 Закона РФ
   № 4802-I «О статусе столицы» Комитет может применять ПО на моделях машинного обучения. **В акте
   записывается факт применения средства и перечисляются полученные данные (п. 9(1).8); сведения размещаются
   в ИАИС «РиН» (п. 9(1).10).** Это требование к нашему протоколу и выгрузке в «РиН» — в ТЗ его нет → T-079.
2. **ГОСТ Р 21.101-2026** действует с 01.04.2026 взамен 21.101-2020, на которую ссылается ТЗ (июль 2026) —
   правила по РД и справочник актов сверить с новой редакцией → T-080.
3. **Акт №13 перечня ТЗ** — это Закон РФ № 4802-I «О статусе столицы» (эксперимент — ст. 14); «№ 61-ФЗ» в ТЗ,
   вероятно, обозначение изменяющего закона. Проверить до закрытия GAP-INSP-06.
4. **ИАИС «РиН»** ведёт реестр объектов, интегрирована с ГИС «Открытый контроль», показывает объекты через
   АИС «Цифровой двойник». Технической спецификации API в открытых источниках нет — T-067 в силе.
5. Надзор в Москве — **Комитет государственного строительного надзора**, без плановых проверок, по программе
   проверок (≤ 6 рабочих дней после извещения); акт — в течение 3 рабочих дней (ПП РФ № 2161, п. 47).
