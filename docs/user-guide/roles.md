description: Как определить свои права в основной платформе и отдельном модуле разметки.

> Применимость: CPU-демо `cfb0ebc6` предназначено для просмотра. В основной платформе проверенные действия сняты на развёрнутых веб-ресурсах с отдельным API `c0851cc7` и синтетическими данными; соответствие исходников опубликованной сборке UI не заявляется. Остальные действия описаны по исходникам и требуют проверки на вашем рабочем стенде и разрешённых прав. Права остальных ролей в этих записях не проверялись. Отдельный модуль разметки снят на `df65e188`; его роли и очередь не приравниваются к основной платформе.

Права назначаются конкретным операциям. Администратор не получает автоматически все действия инспектора. Видимость ссылки в меню не подтверждает право: окончательное решение принимает сервер.

## Основная платформа

| Действие | Разрешённые роли |
|---|---|
| Смотреть проверки, карточки и исходные файлы | Инспектор, супервизор, администратор |
| Загружать и дозагружать пакеты, принимать решения, проверять совпадения, финализировать | Инспектор, супервизор |
| Отменять финализацию с основанием | Супервизор, администратор |
| Смотреть журнал аудита | Супервизор, администратор |
| Редактировать Матрицу и нормативную базу; смотреть мониторинг | Администратор |
| Читать данные раздела моделей и GOLD | ML-инженер, куратор, администратор |
| Выпускать версию GOLD | Куратор, администратор |
| Запускать дообучение ранжирования | ML-инженер, администратор |
| Подписывать публикацию модели | Супервизор, администратор |

Куратору и ML-инженеру закрыты карточки проверок и их исходные файлы; журналы отклонений доступны им сводно в разделе «Модель». У супервизора есть право подписи модели, но текущий экран «Модель» запрашивает также данные, доступные ML-ролям и администратору: сама ссылка не гарантирует полноценный доступ к экрану. Если экран отказывает, администратор проверяет права конкретной операции.

## Отдельный модуль разметки

| Действие | Разрешённые роли |
|---|---|
| Получать задания и сохранять ответы | Верификатор, инспектор, супервизор, администратор, куратор |
| Смотреть собственные ответы и ставить личные отметки | Те же роли |
| Смотреть ответы всех операторов; управлять покрытием и независимым разбором; выпускать проверенный набор | Куратор, администратор |
| Экспортировать данные разметки через предусмотренный API | ML-инженер, куратор, администратор |
| Создавать верификатора | Администратор |

Право экспорта ML-инженера не даёт ему очередь заданий или витрину. Независимый разбор выполняет куратор, который не давал исходный ответ. Учётные записи отдельного приложения могут отличаться от основной платформы.

## Если операция недоступна

Проверьте, на каком приложении и стенде вы находитесь и под какой ролью вошли. На демо отсутствие записи ожидаемо. Если доступ нужен для работы, сообщите администратору конкретное действие, свой логин и текст отказа. Не пользуйтесь чужой учётной записью: автор сохраняется вместе с действием.
