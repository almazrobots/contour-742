## Шаг 1 — откройте нужный стенд

CPU-демо доступно на [nadzorium.almazrobots.ru](https://nadzorium.almazrobots.ru/). Рабочий GPU-стенд — [nadzorium-gpu.almazrobots.ru](https://nadzorium-gpu.almazrobots.ru/). Если браузер сначала запрашивает доступ к самому сайту, используйте выданные администратором реквизиты доступа. Это отдельная защита перед входом в приложение.

## Шаг 2 — войдите

Введите свой логин и пароль. На CPU-демо при включённом гостевом доступе есть кнопка **«Войти для просмотра»**. Пароли в руководстве не публикуются; учётную запись выдаёт администратор.

## Шаг 3 — выберите раздел

| Раздел | Для чего нужен |
|---|---|
| Объекты | Найти объект и связанные проверки |
| Проверки | Открыть пакет, сводку и решения |
| Файлы | Найти документ и его источник |
| Загрузка | Создать пакет или добавить документы |
| Разметка данных | Подтверждать поля по оригиналам |
| Витрина разметки | Смотреть сохранённые ответы |
| Матрица и Нормы | Разобраться в параметрах и правилах |
| Модель, Журнал, Метрики | Сопровождение системы с соответствующими правами |

## Что сделать в первые пять минут

1. Откройте «Проверки» и выберите доступную проверку.
2. Посмотрите «Документы» и статус разбора.
3. Откройте «Сводка сверки» и один источник.
4. Если ваша задача — разметка, перейдите в одноимённый раздел рабочего стенда.

> Если раздел разметки открывается как отдельное приложение, он может попросить отдельный вход. Это не ошибка пароля основной системы: используйте учётную запись, выданную для разметки.

## Если войти не получается

Ошибка 502 означает, что сайт не получил ответ от сервиса; она не доказывает, что пароль неверный. При повторении сообщите администратору адрес, время и текст ошибки. Если не видно нужного раздела, проверьте роль и стенд.

Сначала браузер запрашивает реквизиты внешней защиты сайта. Затем приложение может
показать свою форму входа. Это разные учётные данные. Разметка использует отдельную
сессию приложения: вход в основной стенд не заменяет вход в разметку. Пароль защиты
документации не является общим паролем всех стендов.
