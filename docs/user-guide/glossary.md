---
title: Словарь
description: Термины источников, проверок, разметки и оценки.
---

| Термин | Значение |
|---|---|
| ПД / РД / ИД | Проектная / рабочая / исполнительная документация. |
| Объект | Сущность, к которой относятся документы и проверки; один объект может иметь несколько пакетов. |
| Пакет / проверка | Конкретный состав документов и результаты их обработки. |
| Реестр файлов | Метаданные состава пакета, стадий и редакций; не каталог статей документации. |
| Матрица | Версионируемый справочник параметров и правил сравнения. |
| Извлечение | Найденное машиной поле или значение с привязкой к источнику. |
| Доказательство / источник | Документ, страница или область для самостоятельной проверки вывода. |
| OCR | Распознавание текста изображения или скана; результат может содержать ошибки. |
| Reader / Judge | Компоненты чтения и проверки предложенного результата; их вызов является инференсом, а не обучением. |
| Кандидат | Предполагаемое нарушение, ожидающее решения инспектора. |
| Наблюдение ИИ / гипотеза | Предположение системы; не подтверждённое нарушение. |
| Не представлено | Не получено нужное доказательство; не нулевое значение. |
| Финализация | Фиксация версии протокола; передача во внешнюю систему отслеживается отдельно. |
| Задание разметки | Вопрос по одному или двум источникам; ответ относится к извлечению, не к правовому выводу. |
| Очередь разбора | Ожидающие обработки документы; не очередь вопросов оператору. |
| Очередь разметки | Доступные задания по пригодным доказательствам. |
| Резерв / аренда задания | Временное назначение оператору; после истечения нужно получить действующее задание. |
| Ответ / метка оператора | Сохранённые Да, Нет или Не уверен, комментарий и при наличии исправление. |
| Хороший пример | Личная закладка в витрине; не одобрение эталона. |
| Независимый разбор | Решение другого куратора с основанием, отдельно от исходного ответа. |
| Проверенный набор разметки | Версия заданий после независимого разбора; не автоматически GOLD основной платформы. |
| GOLD | Версионированный эталон основной платформы из допустимых решений финализированных проверок. |
| Инференс | Применение готовой модели без изменения её весов. |
| Дообучение | Изменение обучаемого компонента на подготовленных данных; текущая основная платформа поддерживает ранжирование. |
| Оценочная выборка | Данные для измерения качества, отделённые от настройки и обучения. |
| Precision / точность положительных находок | Доля верных положительных находок среди положительных находок модели на заданной выборке. |
| Recall / полнота | Доля найденных положительных случаев среди всех положительных случаев эталона; требует проверки пропусков. |
| F1 | Гармоническое среднее precision и recall для конкретной оценки. |
| FPR | Доля ложных положительных выводов среди отрицательных случаев эталона. |
| Согласованность | Совпадение ответов разных операторов; не гарантия их правильности. |
| Покрытие | Объём представленных объектов, документов, параметров или случаев; требуется указать знаменатель. |
| Ворота качества | Проверки, допускающие модель к ожиданию подписи; прохождение не равно публикации. |
| Публикация модели | Перевод разрешённой версии в опубликованный статус после предусмотренной подписи. |
| Trace Map | Связи требований, реализации и проверок; статус требования не измеряет качество извлечения. |

Определение качества всегда сопровождается версией модели, набором и способом оценки. Если число не имеет этих сведений, его нельзя переносить на весь корпус.
