Коротко

Что происходит с пакетом после загрузки

Пакет проходит восемь шагов: приём, хранение, очередь, разбор каждого файла в ML, пересчёт проверки, верификация инспектором, финализация и выходной набор. Всё до верификации система делает сама.

Параметр определяется одиннадцатью шагами паспорта L0–L10: общие для всех параметров — приём, редакции, распознавание, ворота, решение; свои у параметра — как искать значение, как нормализовать, откуда брать, как сравнивать и проверять. Пример М-023 ниже — исторический прогон прежнего Mac-стенда (T-129), не замер GPU-профиля.

Бизнес-процесс

От загрузки до протокола

Статус проверки по ТЗ меняется так. Клиент API видит его по process_id — pull-модель, без ожидания ответа.

  1. 1

    Загрузка пакета

    Инспектор · APIПринята

    Архив, папка или файлы уходят в API частями до 200 МБ. Формат определяется по содержимому, пути архива проверяются, архив не распаковывается на диск. Для каждого файла — SHA-256; дубликат по хешу не принимается; антивирус зависит от профиля и в GPU-стенде T-185 выключен. Реестр берётся из пакета или выводится из папок и имён; выведенный реестр подтверждает оператор.

    при сбоефайл отклонён с причиной (формат, размер, повреждение), остальные принимаются«Алтуфьево»78 записей архива → 59 уникальных, 19 дубликатов; 2 повреждённых PDF раздела ООС отклонены; принято 57

Определение параметра

М-023 «Класс конструктивной пожарной опасности»

Что проверяем

Класс конструктивной пожарной опасности здания (С0–С3) не должен понижаться в РД относительно ПД. С0 — лучший класс, С3 — худший.

Основание: Федеральный закон № 123-ФЗ, ст. 87, табл. 22; СП 2.13130.2020, п. 5

Базовый алгоритм — шаги паспорта. Синей чертой отмечены шаги, которые у М-023 свои; остальные общие для всех параметров Матрицы. Справа — что шаг дал на реальном пакете.

  1. L0

    Приём пакета

    общее для всех параметров
    Как

    Файл принимается по содержимому (PDF, DOCX, XML), SHA-256 считается по потоку, дубликат по хешу не передаётся, пакет больше 200 МБ идёт частями дозагрузкой. Файл шифруется и кладётся в S3 под ключом из SHA-256.

  2. L1

    Документ, стадия и редакция

    общее для всех параметров
    Как

    Стадия — по реестру (или папке пакета), шифр и раздел — по реестру или имени файла, эталоном стадии берётся последняя утверждённая редакция.

    Если не получилось

    CLARIFICATION_REQUIRED — редакция не определена

    Стадия — по папке пакета, шифр и раздел — по имени файла. Реестр выведен и подтверждён оператором; без подтверждения редакции не определены, и итог — «нужно уточнение».

    Распознавание текста

    общее для всех параметров
    Как

    Текст с координатами слов берётся из текстового слоя PDF; страница без слоя читается ансамблем OCR.

  4. L3

    Извлечение значения

    особое для М-023
    Как

    В тексте документа ищется оборот «класс конструктивной пожарной опасности» и значение С0–С3 не дальше 160 знаков после него. Каждое упоминание сохраняется отдельно: страница, рамка, цитата, раздел документа. Упоминания соседнего здания, таблицы норм и заголовки без значения отсеиваются с причиной.

  5. L4

    Нормализация

    особое для М-023
    Как

    Латинская C → кириллическая С, буква О в номере → 0. «Не ниже С0» — ограничение, а не точка. Значение вне шкалы С0–С3 отбрасывается.

    Если не получилось

  6. L5

    Выбор источника стадии

    особое для М-023
    Как

    ПД — только комплект, связанный с РД по базовому шифру. Внутри стадии значение берётся из самого приоритетного раздела: ПД — ПЗ → ПБ → АР → КР → прочие; РД — АР → КР → КЖ → КМ → прочие. Ограничение «не ниже» раздела с тем же приоритетом уступает точному значению.

    Если не получилось

    MISSING_EVIDENCE — у стадии нет ни одного упоминания

Остальные параметры

Как считаются другие 131 параметр

Общие шаги (приём, редакции, распознавание, ворота, решение, решение инспектора) — те же. Свои шаги берутся из строки Матрицы: значение ищется по якорям и шаблону параметра, сравнение — по правилу сравнения (дельта в процентах, «не ниже эталона», «не выше эталона», совпадение). Паспорт со своим алгоритмом, как у М-023, — следующий шаг для других параметров.

Паспорт любого параметра открывается щелчком по коду в разделе «Матрица» интерфейса; шаги на этой странице и в паспорте берутся из одного источника — data/seed/passports.
