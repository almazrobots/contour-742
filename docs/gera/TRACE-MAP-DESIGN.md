## Детальная трасса (T-097, 2026-09-26, весь ТЗ)

Вкладка «Детальная трасса» (`TRACE-MAP.html?view=detail`). Слева — страница ТЗ, собранная из текстового слоя PDF
на исходных координатах (`data/seed/tz-layout.json`; сам PDF в git не попадает). На ней области с точностью
до слова, строка таблицы — полосой. Справа по каждой области — «колбаса»: атом → БП → БФ → БО → сервис → требование
(правило, НФТ, диалог, данные) → код → тест. Красный пунктир на любом этаже — обрыв.

- Разметка областей: `docs/tz/regions/<раздел>.yaml`, поля — `docs/tz/regions/README.md`. Проверка раздела: `node scripts/tz-detail.mjs S4`, строки для разметки: `--dump S4`.
- Обложка без текстового слоя — область `whole` с текстом, перенесённым вручную.
- Гейт: каждое слово раздела в пределах `scope` входит в область, фразы найдены, атомы и узлы существуют.
- Типы областей: атомы · бизнес-уровень (фраза называет процесс) · заголовок пункта · требований нет ·
  **не разложено** (кандидат в атом) · **ТЗ ≠ Матрица** (строка требует раздел, по которому в Матрице 0 параметров).
- Весь ТЗ идёт одним потоком: слева 32 страницы подряд, справа все цепочки подряд со сквозной нумерацией областей.
- Стороны прокручиваются независимо и связаны только кликом (решение владельца 26.09: синхронная прокрутка
  оказалась сложной). Клик по фрагменту в PDF прокручивает трассу к его цепочке, клик по цепочке прокручивает PDF к
  фрагменту, клик по разделу в ленте прокручивает обе стороны к началу раздела.
- Лента разделов показывает готовность каждого раздела и подсвечивает текущий по положению PDF.
- Фрагмент, связанный с пробелом модели (`gap` в разметке), помечен меткой GAP-INSP-NN с текстом пробела.
