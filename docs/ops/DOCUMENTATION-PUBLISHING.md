# Публикация документации и перенос приложения

Публичный адрес: https://nadzorium.almazrobots.ru/docs/gera/TRACE-MAP.html.
Документация публикуется в `/opt/nadzorium/var/docs` на hk-ru (31.192.110.44).
Host Caddy обслуживает `/docs/*` напрямую через `handle_path` + `file_server`,
под прежней Basic Auth. `/docs/presentation/*` сохраняет отдельный маршрут.
Приложение может находиться на другом хосте: на 29.09 его upstream —
127.0.0.1:45902, SSH-туннель к 202.148.52.9:45901.

При переносе приложения сохранять маршрут `/docs/*`: встроенная в образ или
новый compose копия документации не должна заменять опубликованные материалы.
Источник конфигурации: deploy/demo/Caddyfile.nadzorium; при применении сохранять
актуальный upstream приложения и сертификат CA (шаблон содержит прежний стенд).

После публикации проверять публичный HTTPS-адрес, а не только каталог или
прежний nginx: SHA-256 ответа должен совпадать с файлом. Для браузерной проверки
статических страниц scripts/check-trace-docs.mjs принимает TRACE_DOCS_BASE и
TRACE_DOCS_AUTH_FILE (приватный JSON с username/password/origin, вне git).
Запуск — через remote-run. Проверка не запускает приложение или ML.
