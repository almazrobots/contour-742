# 08. Дорожная карта

Стоп-код хакатона — **29.09.2026 23:59 МСК**. Фриз — 28.09 20:00. До него — только то, что ложится
на существующий код и измеряется на синтетике (ADR-0002). Порядок — по вкладу в 30 минут цикла.

## Решения владельца, без которых нельзя начинать

### Волна 1 — лист и клавиши (27.09)

Работает внутри текущего `Verify.tsx`, без смены языка.

| Что | Файлы | Эффект |
|---|---|---|
| Кроп вокруг рамки, цифры ≥ 14 px, камера, `Space` — весь лист | `components/Sheet.tsx` | главный: 10–25 с на кандидата |
| Кэш документов pdf.js, предрендер следующих трёх | `Sheet.tsx`, `Verify.tsx` | 0,4–2 с на переходе |
| Клавиши по `e.code` | `Verify.tsx`, `Inspections.tsx` | `J`/`K` в русской раскладке |
| `2` → `1…6`, комментарий из причины | `Verify.tsx` | снятие с клавиатуры |
| Оптимистичное решение без перезагрузки проверки, лоток вместо тостов | `Verify.tsx` | 200–800 мс на решении |
| `reopen` для `Z` (OS-INSP-4.1.15), счётчик действий (4.1.16) | `services/inspections.ts`, `domain` | отмена и замер ТЗ 9.3.6-02 |
| Равный вес трёх решений | `Verify.tsx`, `styles.css` | убирает подталкивание к согласию |
| `Enter` из «Мне сейчас» сразу в конвейер | `Inspections.tsx` | минус два перехода |

### Замер (28.09 до 20:00)

Одна синтетическая проверка (`ml/synth/generate.py`), два прогона: механики выключены и включены.
`verify-timing.ts` — активное время, решений, действий на решение, время до доказательства. Цифры —
замер на себе, а не на пяти инспекторах; так и пишем.

## Сценарий демо, 3 минуты

Секундомер цикла в углу экрана всё время — он уже считается в `verify-timing.ts`.

| Время | Кадр | Что видит жюри |
|---|---|---|
| 0:00–0:20 | Перетаскиваем синтетический пакет с реестром | принятые файлы с SHA-256, отклонённый с причиной; перечень «не представлено» в первую минуту |
| 0:20–0:40 | Готово: 132 параметра — 22 на оценку, 12 не представлено, 84 «расхождения нет» | комплектность отдельно от расхождений |
| 0:40–1:10 | Партия чистых: 30 карточек клавишей `J`, «граница 10 %, SYNTH», `⇧Enter` | 84 записи без просмотра по одному, выборка в аудите |
| 1:10–2:00 | Конвейер: Прицел, `1` / `2` + причина; «не то изменение» закрывает ещё пять | доказательство на листе за доли секунды, решение одной клавишей |
| 2:00–2:25 | Представлено по требованию: «перенесено 18, заново 3» | работа не теряется |
| 2:25–2:50 | Сборка сводки из чипов, `F`, окно отмены, текст для акта | юридически пригодный выход |
| 2:50–3:00 | Секундомер: цикл против 30:00 по ТЗ; действий на решение — 1 | тезис одной строкой |

Оговорка в кадре: данные синтетические (ADR-0002), цифра — демо-прогон, приёмка — на пяти инспекторах.
