# Отложенный состязательный набор v2 волны W3 (T-210)

## Назначение

Финальный слепой замер W3. Первый отложенный набор (`data/holdout/w3`) после первого замера
частично раскрыт исполнителям (классы ошибок), поэтому итоговое качество меряется на этом наборе.

**До финального замера набор закрыт для исполнителей и тимлида W3**: не открывать, не цитировать,
не подбирать под него правила, промпты и пороги. Открывает только тот, кто запускает замер.
После замера набор считается раскрытым; для следующего слепого замера нужен v3.

Набор написан независимо от `data/holdout/w3`, `data/dev/w3` и кода веток `feat/w3-*`. Основание —
`docs/research/TO-BE-операции-сравнения.md` (§10 ворота, §11 карточки CMP-06/07/09/17/18/22/23/25/29,
§12 проверки VER, §13 таблица решений, §17 строки Матрицы), нормативные значения из общих знаний
и практика проектной документации (ПЗ, ПЗУ/ГП, АР, КР/КЖ/КМ, ИОС1/ЭМ, ПОС, ПОД, ППР, ОДИ, ППМ, ИД).
Нормы приведены по памяти и служат только ориентиром для разметки (например, минимальный продольный
уклон проезда ≈ 5 ‰, предельный ≈ 80 ‰), это не юридическая проверка.
Все тексты выдуманы: реальных адресов, шифров, организаций и ФИО нет (ADR-0002).

## Правила разметки

- M-048: подступенок > 220 мм или проступь < 250 мм (СП 1.13130 п. 4.4.3) — CANDIDATE; хуже 150 / 300 из
  Матрицы, но в пределах СП — SUSPICION.
- M-091: SAME и REFINED — не нарушение; CHANGED — CANDIDATE.
- M-082: рост критического этапа больше 10 % — CANDIDATE; ровно 10 %, сокращение, некритический этап — не нарушение.
- M-087: перестановка по датам — CANDIDATE; перестановка только строк таблицы без дат — SUSPICION.
- M-096: нет документа ИД — MISSING_EVIDENCE; нет реквизита в имеющемся акте или дата акта раньше работ — CANDIDATE.
- M-043, M-106: оговорка «до 15 человек» к конкретному помещению — не нарушение; только Л/П — NOT_COMPARABLE;
  сужение пути открытой дверью — SUSPICION.
- Изменение с подтверждённым утверждением (откорректированная ПД с положительным заключением) — NEGATIVE_VERIFIED;
  изменение без подтверждения утверждения — CANDIDATE (CMP-29).
- Отсутствие проверяемо доказывается только по полному покрытию; «альбом не представлен» — MISSING_EVIDENCE.

## Формат

`cases.jsonl`, одна строка — один случай:

```json
{"id": "H2-M-033-01", "param": "M-033",
 "stages": {"PD": [{"discipline": "ПЗУ", "text": "…"}], "RD": [{"discipline": "ГП", "text": "…"}], "ID": []},
 "expected": {"status": "CANDIDATE", "accept": ["SUSPICION"]},
 "adversarial": false, "why": "…"}
```

- `stages.PD / RD / ID` — фрагменты документов стадии; пустой список — документа стадии нет.
  ППР и календарный график ППР относятся к стадии RD.
- `expected.status` — один из CANDIDATE, NEGATIVE_VERIFIED, MISSING_EVIDENCE, NOT_COMPARABLE,
  NOT_APPLICABLE, SUSPICION.
- `expected.accept` — допустимые альтернативы. Осторожный ответ вместо нарушения допускается;
  CANDIDATE не входит в `accept` ни одного случая — ложное нарушение не допускается никогда.
- `adversarial` — случай с ловушкой (единицы, формы записи, таблицы, примечания, цитаты норм, отрицания,
  чужой элемент или система, утверждённые и неутверждённые изменения, OCR-шум, ИД против РД,
  внутренняя несогласованность, отсутствующие документы).
- `why` — обоснование разметки, для разбора после замера.

## Метрики

Ответ системы по случаю — итоговый статус по параметру.

1. **FP-нарушение (главная, цель 0)** — ответ CANDIDATE на случай, где `expected.status` не CANDIDATE.
   Отдельно считать долю FP среди состязательных.
2. **Recall по CANDIDATE** — доля случаев с `expected.status = CANDIDATE`, где ответ CANDIDATE.
3. **Воздержания** — точность на случаях с ожидаемыми MISSING_EVIDENCE / NOT_COMPARABLE / NOT_APPLICABLE /
   SUSPICION, плюс матрица ответов 6×6.
4. **Ответ из `accept`** — засчитывается как «не ошибка»: не FP и не попадание в Recall
   (например, SUSPICION на ожидаемый CANDIDATE не FP, но и не найденное нарушение).
5. Всё остальное — ошибка; по параметрам и отдельно по состязательным случаям.
