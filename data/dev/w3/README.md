# Dev-набор W3 — для настройки экстракторов

**Назначение:** на этом наборе исполнители W3 (T-211…T-214) настраивают экстракторы и сравнение. Отложенный набор
`data/holdout/w3` — только для замера; исполнителям он закрыт, настраиваться по нему нельзя.

Набор писался независимо от отложенного (автор его не открывал) и от кода веток W3. Все тексты выдуманы: без реальных
адресов, шифров и организаций, корпус не использован (ADR-0002).

## Состав

`cases.jsonl` — 171 случай по 14 параметрам: M-033, M-048, M-053, M-063, M-070, M-092, M-095, M-122, M-091, M-082, M-087,
M-096, M-043, M-106 (12–13 на параметр, 52 помечены `adversarial`).

По статусам: NEGATIVE_VERIFIED 66, CANDIDATE 47, NOT_COMPARABLE 18, MISSING_EVIDENCE 15, NOT_APPLICABLE 15, SUSPICION 10.

## Формат строки

```json
{"id": "DEV-M-033-01", "param": "M-033",
 "stages": {"PD": [{"discipline": "СПЗУ", "text": "…"}], "RD": [...], "ID": [...]},
 "expected": {"status": "NEGATIVE_VERIFIED", "accept": []},
 "adversarial": false, "why": "…"}
```

- Пустой список стадии — документа этой стадии нет. ППР и календарный график относятся к стадии RD.
- `expected.status` — основной ожидаемый статус; `expected.accept` — другие статусы, которые тоже засчитываются
  (двусмысленные случаи: осторожный ответ вместо нарушения допустим, ложное нарушение — нет).
- `adversarial: true` — ловушка: норма из СП вместо проектного значения, чужой корпус или элемент, похожее слово в другом
  смысле, отрицание, ссылка без содержания.
- `why` — почему ожидается именно этот статус.

## Что покрыто по форме записи

Таблицы (строки через «|», шапка отдельной строкой, единица в шапке, значение в соседней ячейке), примечания к чертежам
(«Примечания: 1. …»), текст ПЗ/ПОС/ПОД, спецификации и экспликации, ведомости дверей и проездов, штампы и таблицы
изменений, сокращения («прод. укл.», «i=», «‰» / «промилле» / «%», «ступ.», «кол-во», «шт.», «д.ш.», «т/о»), число до
и после подписи, числа словами, переносы, лишние пробелы, латиница вместо похожих кириллических букв, умеренный
OCR-шум. Отказы: документа нет → MISSING_EVIDENCE; сноса нет или элемент не на пути эвакуации → NOT_APPLICABLE;
другой элемент или неоднозначный пересчёт → NOT_COMPARABLE; нечитаемое значение или ссылка без содержания → SUSPICION.
